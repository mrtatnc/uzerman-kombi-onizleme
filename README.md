# Uzerman React Animasyon Laboratuvarı

React Bits görünümünden esinlenen, **ek animasyon bağımlılığı olmayan** interaktif React/Vite önizlemesi.

## Önizleme

[StackBlitz üzerinden çalıştır](https://stackblitz.com/github/mrtatnc/uzerman-kombi-onizleme/tree/reactbits-animation-preview?startScript=dev)

> Bu çalışma **reactbits-animation-preview** dalındadır. Orijinal kombi önizlemesi **main** dalında aynen korunur.

## Yerel kurulum

```bash
npm install
npm run dev
```

## İçerik

- Fade, Slide Up, Blur, Split Text
- Gradient Text, Shiny Text, Glare Hover, Count Up
- CSS + IntersectionObserver + requestAnimationFrame
- React.lazy ve Suspense ile gerçek kod ayırma
- LocalStorage üzerinden animasyon tercihleri ve favori
- Erişilebilirlik için reduced-motion, responsive tasarım

Bu demo orijinal React Bits paketlerinin birebir kopyası değildir; aynı animasyon stillerinin hafif uygulamasıdır. İstatistik sayıları örnektir.
